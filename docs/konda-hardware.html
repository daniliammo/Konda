Konda до железа

Что нужно добавить, чтобы на Konda писались драйверы и прошивки как на C — не теряя нулевой цены безопасности и близости кода к псевдокоду.

Рамка доклада

Konda уже безопаснее C и во многом выразительнее. Пробел — не в безопасности, а в двух осях: доступ к «голому» железу (MMIO, прерывания, bare-metal) и выразительность (сахар, приближающий код к псевдокоду). Каждая фича ниже спроектирована так, чтобы инвариант №1 остался цел: любая безопасность — статическая, релиз работает со скоростью C. Опасное к железу — за гейтом небезопасно {} либо спрятано в типобезопасную обёртку нулевой цены (как регистр-хендл).

Блок A · без этого нет драйверов

A.Системный слой: железо напрямую

MMIO, регистры, прерывания, bare-metal. Здесь Konda обязана дотянуться ровно туда, куда достаёт C — но с типами и статическими проверками там, где они бесплатны.

A1

изменчивый<T> — доступ к MMIO-регистрам

Драйвер немыслим без volatile: чтение/запись регистра нельзя выкидывать и переупорядочивать. Сейчас это выразимо только через асм. Нужен типизированный регистр-хендл: адрес формируется один раз за гейтом, дальше доступ безопасен и компилируется в один volatile load/store.

0 рантайма адрес — за небезопасно инв. №1 · №2
C
// сырой volatile, ничем не защищён
volatile uint32_t *UART = (void*)0x40011000;
*UART = 0x1;
uint32_t s = UART[1];
Konda — предложение
изменчивый UART_DR по адресу 0x4001_1000
// хендл типизирован; доступ — безопасный,
// границы регистрового блока статичны
UART_DR.записать(0x1)
пусть s = UART_DR.прочитать()
A2

Регистровые блоки: структура по адресу

Периферия — это struct полей по фиксированному базовому адресу (SVD-модель). Хочется описать блок один раз и обращаться по именам полей, а не по смещениям. Раскладка проверяется статически (выровнять/смещения), доступ — volatile.

0 рантайма читаемость инв. №1
C
struct USART { volatile uint32_t SR, DR, BRR; };
#define USART1 ((struct USART*)0x40011000)
USART1->BRR = 0x1A1;
Konda — предложение
изменчивая структура USART {
  целое32 SR; целое32 DR; целое32 BRR;
}
пусть USART1 = USART по адресу 0x4001_1000
USART1.BRR = 0x1A1   // → volatile store
A3

Битовые поля и упакованная структура

Регистр — это именованные битовые поля (EN=бит 0, BAUD=биты 15:4). Побитовые операции есть (§8), но ручные маски — источник ошибок. Нужны типизированные поля с проверкой ширины на этапе компиляции и упакованная раскладка для протоколов/DMA-дескрипторов.

0 рантайма статическая ширина полей меньше масок вручную
C
// маска/сдвиг руками — легко ошибиться
CR1 = (CR1 & ~(0xFFF << 4)) | (baud << 4);
CR1 |= 1;   // EN
Konda — предложение
упакованная структура CR1 {
  EN:   бит[0]
  BAUD: бит[15:4]   // ширина 12, проверена
}
CR1.BAUD = baud   // baud > 0xFFF → ошибка компиляции
CR1.EN = 1
A4

Прерывания и размещение: прерывание, в секции

Прошивке нужны обработчики прерываний (особая ABI, без обычного пролога), naked-функции для boot/переключения контекста и размещение в секциях линкера (таблица векторов в .isr_vector, код в RAM). Всё это — атрибуты функции: ноль рантайма, только влияние на кодоген/линковку.

0 рантайма тело часто небезопасно атрибут кодогена
C (gcc)
__attribute__((interrupt))
void SysTick_Handler(void) { tiks++; }

__attribute__((section(".isr_vector")))
const vector_t vectors[] = { … };
Konda — предложение
прерывание ничего SysTick() {
  тики++
}

конст векторы: [Вектор] в секции ".isr_vector"
  = [ сброс, nmi, hard_fault, … ]
A5

Bare-metal режим: --свободный

Сегодня даже --без-стандартной-библиотеки оставляет рантайм, невозможный на голом железе: jemalloc, бэктрейс (§27), защита стека через SIGSEGV на alt-стеке (§29). Нужен freestanding-профиль: без ОС-зависимостей, кастомная точка входа _старт, паника → ловушка-хук (wfi/reset), только статическая память или пулы (§30).

профиль сборки без ОС-рантайма нет кучи по умолчанию
Сейчас — зашито
// в каждый бинарник:
//  · jemalloc (§24)
//  · backtrace + -rdynamic (§27)
//  · SIGSEGV-alt-stack guard  (§29)
// на MCU без ОС — неприменимо
Konda — предложение
konda --свободный \
      --целевая-архитектура=thumbv7em \
      прошивка.конда

// без кучи/бэктрейса/сигналов;
// точка входа _старт; паника → хук:
при панике { wfi_навсегда() }
A6

Именованные интринсики и барьеры

dsb/isb/wfi/nop, барьеры памяти, доступ к спец-регистрам (CONTROL, PRIMASK). Сейчас — только сырой асм (§60), непортируемо и без проверок. Обёртки-интринсики: читаемо, портируемо между дугами, всё так же ноль рантайма.

0 рантайма портируемее, чем асм на базе §60
Сейчас (§60)
небезопасно {
  асм("dsb sy" : : : "memory")
  асм("wfi")
}
Konda — предложение
барьер_данных(последовательный)
ждать_прерывания()   // wfi
// интринсик знает дугу → верный асм

Блок B · универсальность и псевдокод

B.Выразительность: код как замысел

Приближение к псевдокоду — это меньше церемонии на строку смысла. Почти всё ниже — чистый десугар в парсере (как цикл §46, для_каждого §56, составное присваивание §45): ноль правок семантики/кодогена, ноль рантайма.

B1

Вывод типа локали: пусть

Тип локали часто очевиден из инициализатора. пусть x = … убирает шум, оставаясь полностью статическим (тип выводится в компиляторе, в C эмитится конкретный тип). Явный тип по-прежнему доступен, где помогает читателю.

0 рантаймаменьше шуматип статичен
Сейчас
целое32 длина = как<целое32>(strlen(с))
Точка ц = центр(окно)
Konda — предложение
пусть длина = как<целое32>(strlen(с))
пусть ц = центр(окно)   // тип выведен
B2

Циклы по диапазону: для i в 0..n

Каноничный счётный цикл — самый частый паттерн. Диапазоны 0..n (полу-открытый), 0..=n, шаг по 2 читаются как псевдокод. Десугар в каноничную форму для → элизия границ (BCE) работает как раньше, тело векторизуется.

✓ реализовано §670 рантаймапсевдокоддесугар в §38-цикл
Сейчас
для и = 0; и < n; и++ {
  сумма += данные[и]
}
Konda — предложение
для и в 0..n {
  сумма += данные[и]
}
для и в 0..n по 2 { … }
B3

Разворот под условием: если пусть

Null-безопасность есть (§1), но разворот возможно<T*> и вариантов sum-типа многословен. если пусть / пока пусть связывают развёрнутое значение прямо в условии — безопасно и коротко, как в Swift/Rust.

0 рантаймаэргономика null/sumна базе §1 · §33
Сейчас
возможно<Узел*> п = найти(5)
если п != нуль {
  // п сужен, читаем п.знач
}
Konda — предложение
если пусть п = найти(5) {
  использовать(п.знач)   // п: Узел* тут
}
пока пусть стр = очередь.след() { … }
B4

выбор и если как выражения

Часто ветвление лишь вычисляет значение. Разрешить выбор/если в позиции выражения убирает временную переменную и «прокол» присваиваний в каждой ветке — прямее замысла.

0 рантаймаменьше временныханализ дивергенции есть
Сейчас
целое32 знак
если x > 0 { знак = 1 }
иначе { знак = -1 }
Konda — предложение
пусть знак = если x > 0 { 1 } иначе { -1 }

пусть имя = выбор код {
  200 => "OK",  404 => "нет",  _ => "?"
}
B5

Кортежи, деструктуризация, множественный возврат

В C «несколько результатов» — это out-параметры и ручная распаковка. Кортежи (a, b) и деструктуризация пусть (ч, о) = делим(...) выражают это прямо. Реализуемо через анонимную структуру нулевой цены.

0 рантаймаубирает out-параметрыанон. структура
C
int q, r;
divmod(a, b, &q, &r);   // out-параметры
Konda — предложение
функция делим(a, b) -> (целое32, целое32) { … }
пусть (ч, о) = делим(a, b)
B6

Литералы железа: 0b, разделители, единицы

Регистровая работа тонет в длинных числах. Двоичные 0b1010, разделители 0x4002_0000 / 1_000_000 и суффиксы-единицы (16_МГц, 100_мс) резко повышают читаемость и убирают арифметические описки. Чистый лексер, ноль рантайма.

✓ §66: 0x / 0b / _0 рантайматочность чтениятолько лексер

Реализовано (§66): 0x/0b и разделители _ (кодоген вырезает _, префиксы — как есть). Осталось: суффиксы-единицы (16_МГц → 16000000) — низкий приоритет, чистый сахар лексера.

Сейчас
частота = 16000000
маска = 4026531840   // это что?
Konda — предложение
частота = 16_000_000        // или 16_МГц
маска = 0b1111_0000_0000_0000_0000_0000_0000_0000
B7

Проброс ошибок ? и отложить

Результат<T,E> есть (§33), но ручная распаковка на каждом шаге многословна. Оператор ? пробрасывает ошибку вверх одним знаком. отложить {} — ad-hoc очистка на выходе из области (RAII уже покрывает владеющее; defer нужен для «выключить пин», «снять лок»).

0 рантаймалинейный happy-pathна базе §33 · RAII
Сейчас
выбор открыть(п) {
  Успех(ф) => { … }
  Провал(е) => { вернуть Провал(е) }
}
Konda — предложение
пусть ф = открыть(п)?       // провал → ранний возврат
включить_такт(GPIOA)
отложить { выключить_такт(GPIOA) }
B8

Именованные и умолчания аргументов; псевдонимы типов

Вызов настроить(115200, 8, 1, 0) нечитаем. Именованные аргументы (скорость: 115200, стоп: 1) самодокументируют. Псевдоним тип Гц = целое32 и newtype дают доменные имена без рантайм-цены. Всё разрешается на этапе компиляции.

0 рантаймасамодокументируеморазбор/семантика
Сейчас
настроить(115200, 8, 1, 0)
// порядок и смысл — в голове
Konda — предложение
тип Бод = целое32
настроить(скорость: 115200, биты: 8, стоп: 1)

Границы

Чего делать нельзя

Универсальность не должна размыть то, что делает Konda собой. Три красные линии.

№1 Ни грамма рантайма ради удобства

Каждая фича обязана исчезать в релизе (десугар, тип, атрибут). Если фича требует рантайм-механизма — она проектируется как отладочный guard, вырезаемый в релизе, либо отклоняется. Никакого GC, никаких исключений с раскруткой стека.

№2 Голое железо — только за гейтом или в обёртке

Формирование адреса MMIO, reinterpret, спец-регистры — за небезопасно {}. Но «наружу» выдаём типобезопасный хендл (A1–A3), чтобы 99% драйверного кода оставалось безопасным. Сохраняем «нет сырого &»: мутация — через изменяемый/вывод.

§6 Каждую фичу — сразу с максимальным размахом

Урок §55: «v1 с ограничением» рождает второй заход. Диапазоны, кортежи, битовые поля проектируем на весь диапазон паттернов сразу — снимая ограничения по максимуму, не жертвуя инвариантом №1.
